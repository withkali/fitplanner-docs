Questions fréquentes

  • Jusqu’où puis-je utiliser l’application gratuitement ? Jusqu’à ce que vous ayez terminé vos 2 ou 3 premières séances (selon le nombre de séances par semaine que vous avez défini), vous pouvez utiliser gratuitement toutes les fonctions, y compris l’application Apple Watch. Pour commencer une nouvelle séance ensuite, un abonnement est nécessaire. Aucun paiement n’est prélevé automatiquement à la fin de l’utilisation gratuite.
  • Comment résilier l’abonnement ? Résiliez dans l’app Réglages de l’iPhone, sous [votre nom] → Abonnements. Tant que vous êtes abonné, vous pouvez aussi ouvrir le même écran depuis l’application, via Profil → Gérer l’abonnement. Après la résiliation, vous pouvez continuer à utiliser Pro jusqu’à la fin de la période payée.
  • Je souhaite être remboursé. Le paiement et le remboursement sont traités par Apple. Veuillez en faire la demande à Apple sur reportaproblem.apple.com.
  • Mon abonnement n’apparaît pas sur un autre appareil. Connectez-vous avec le même compte Apple, puis touchez Restaurer l’achat dans la carte d’abonnement tout en haut de l’onglet Profil de l’application. Si vous restaurez l’achat dans un autre compte FitPlanner AI, Pro est transféré à ce compte et désactivé sur le compte précédent.
  • Il est indiqué que le paiement a échoué. Vérifiez le moyen de paiement de votre compte Apple. Pendant la période de grâce (actuellement 3 jours) durant laquelle Apple retente le paiement, vous pouvez continuer à utiliser Pro.
  • Je souhaite changer la langue ou les unités (kg/lb, cm/ft·in). Vous pouvez le faire dans l’onglet Profil de l’application.
  • Je souhaite supprimer mon compte et mes données. Consultez les instructions de suppression du compte et des données.
  • Comment mes données personnelles sont-elles traitées ? Consultez la politique de confidentialité.
